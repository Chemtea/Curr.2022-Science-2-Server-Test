# 과학 플랫폼 서버 구조 테스트

[테스트 페이지](https://chemtea.github.io/Curr.2022-Science-2-Server-Test/) · 대상: **Chemtea-lab / science-platform-test / `rerykeslgwhamreoskgx`** (Free, 서울). 운영 프로젝트와 데이터는 변경하지 않았습니다.

## 현재 상태 — 2026-09-13

Supabase 재개 후 DB 스키마와 서버 함수 설치를 완료했습니다. 첨부 수업 **15차시**, 학습지 PDF **2개**, 수행평가 **3개**, 교사용 답안 **1개**를 등록했습니다. 초기 수업·일반 학습지는 학생 공개로 등록했으며 현재 목록은 이후 공개·보관 상태에 따라 달라집니다. 기존 단원·차시·단계 잠금도 적용됩니다. 수행평가와 답안은 교사 전용입니다. 3단원 4차시는 임의로 만들지 않았습니다.

**자료 관리 탭은 교사 관리자 모드에서만 표시됩니다.** 탭을 누르면 팝업이 열립니다. 학생 화면에는 큰 서버 자료실 패널이나 관리 탭이 표시되지 않습니다.

자료 관리에는 **사용 중 / 보관함** 탭이 있습니다. 보관한 자료는 보관함에서 보관일과 함께 확인하고 **교사 전용으로 복원**할 수 있습니다. 복원은 기존 자료 ID·본문·PDF·제출 기록을 유지하며 학생에게 자동 공개하지 않습니다.

## 자료 올리는 방법

1. index에서 교사 관리자로 로그인하고 **관리자 모드 → 자료 관리**를 누릅니다.
2. 자료 종류·제목·단원을 선택하고 파일을 올립니다. 새 공통 수업은 **공통 수업팩 양식 받기**로 받은 JSON을 사용합니다. 기존 HTML과 학습지 PDF도 등록할 수 있습니다.
3. **서버에 임시저장**한 뒤 자료를 열어 확인합니다. 이 단계에서는 학생에게 공개되지 않습니다.
4. **학생 공개**를 선택하면 수업 목록 또는 학습지함에 반영됩니다. 연결된 잠금도 확인하고 필요한 범위만 해제합니다. 교사용 답안에는 학생 공개 기능이 없습니다.

PDF는 10MB, HTML·JSON은 2MB 이하입니다. 학습지의 수업 ID를 해당 차시와 연결하면 차시의 PDF 패널에서도 열 수 있습니다. 수행평가는 학생 공개 외에도 평가관·단원·활동 잠금이 모두 해제되어야 학생에게 전달됩니다.

일상적인 자료 추가·수정은 GitHub 수정이나 재배포가 필요 없습니다. 로그인·단계 잠금·퀴즈·학습지 필기 기능은 공통 파일로 관리합니다. JSON 수업팩은 이 공통 화면을 사용하고, 기존 단독 HTML은 로그인 정보에 접근할 수 없는 별도 화면에서 실행됩니다. 임의 HTML의 공통 수업팩 자동 변환이나 새 실험 자동 생성은 포함하지 않습니다.

## 보관한 자료 다시 사용하기

1. **관리자 모드 → 자료 관리 → 보관함**을 엽니다.
2. 자료 제목·단원·보관일을 확인하고 **교사 전용으로 복원**을 누릅니다.
3. **사용 중** 탭에서 복원한 자료를 열어 확인합니다.
4. 학생에게 제공할 자료만 **학생 공개**를 누르고 관련 잠금을 확인합니다. 모범답안은 복원 후에도 교사 전용입니다.

보관은 삭제가 아닙니다. 원문·PDF·기존 제출 기록을 유지하며 학생의 새 조회를 차단합니다. 보관함은 교사 관리자만 조회할 수 있고, 보관 중인 본문은 교사도 복원한 뒤 열 수 있습니다. 복원은 새 자료를 만드는 동작이나 이전 내용 버전으로 되돌리는 동작이 아닙니다. 이미 학생이 내려받은 사본은 회수하지 않습니다.

## 채점과 자료 보호

- 학생의 실제 선택 번호를 서버의 비공개 정답으로 채점합니다. 브라우저가 보낸 점수는 사용하지 않으며, 예전 점수 제출 API는 차단했습니다.
- 새 채점 결과는 기존 교사 제출 대시보드의 기록과 연결됩니다. 최초 제출 포인트는 기존 확정 규칙을 따르며, 채점·제출 기록·포인트를 한 트랜잭션으로 저장합니다. 같은 요청을 다시 보내도 중복 지급하지 않습니다.
- 자료 API가 기존 로그인 세션의 만료·계정 상태·교사 권한을 서버에서 확인합니다. 자료 테이블의 RLS와 직접 접근 제한, 비공개 PDF 저장소를 적용했습니다. 학생 공개된 PDF도 인증된 자료 API를 거쳐 전달합니다.
- 교사용 답안은 교사에게만 전달합니다. 보호 평가 HTML의 스크립트 실행도 제한합니다. 정답·해설 원본과 인증 키는 공개 저장소에 올리지 않습니다.
- 테스트 로그인과 필기는 전용 저장 키를 사용합니다. 운영 페이지의 로그인 정보를 가져오지 않습니다.

**과거 Git 커밋에 공개됐던 평가·답안은 이번 변경만으로 지워지지 않습니다.** 현재 공개 파일은 보호 안내로 바꿨지만, 이미 공개된 답안을 다시 비밀로 만들 수는 없습니다. 기존 계정의 최초 비밀번호 등록에 초대·활성화 코드를 요구하는 개선도 아직 적용하지 않았습니다.

## 검증 범위

실제 서버에서 보관함 조회·교사 전용 복원·학생 접근 차단·중복 복원 충돌을 확인했습니다. 같은 자료 ID·본문·비공개 정답·기존 제출 기록이 유지되는 것도 DB에서 확인했습니다. 검증용 자료와 계정·세션은 제거했습니다.

로컬 API·권한·세션·잠금 검사는 **49개 모두 통과**했습니다. 실제 테스트 DB에서는 가상 자료로 서버 재채점, 기존 대시보드의 O/X·최초/최고 기록, 최초 포인트만 지급, 요청 재시도, 승인된 외부 계정, 관리자 아이디 차단, 잠금·버전·계정 상태 검사를 통과했습니다. DB 검증용 자료는 트랜잭션 안에서 모두 되돌렸습니다.

실제 HTTP 검사도 완료했습니다. 학생 로그인, 목록 17개 조회, 교사 자료 읽기, 학생의 평가·답안 조회 및 업로드 거절, 서버 채점·현황판 기록·중복 지급 방지, PDF 원본 일치, 새 자료 임시저장→공개→목록 자동 반영→버전 충돌→보관을 확인했습니다. 공개 브라우저 키의 DB 직접 조회도 거절됐습니다. 검증용 계정·세션·임시 자료는 제거했습니다. 

검증 중 일시적인 서버 503 오류가 있었으며, 저장 상태를 확인한 뒤 재시도해 통과했습니다. 요청 대기는 60초이며 변경 요청을 자동 재전송하지 않습니다. 서버 연결이 실패하면 새로고침 후 다시 확인하세요.

수행평가 3개와 답안은 스크립트를 제거한 교사 보관본입니다. 기존 평가의 상호작용·별도 제출 흐름은 아직 이관하지 않았습니다. 태블릿 필기, 실제 마이크·3D 렌더링, 이번 자료 관리 이외의 기존 관리자 API는 추가 검증이 남습니다.

## 개발 파일

- `index.html`, `assets/content-*`: 자료 관리 팝업·서버 목록·조회
- `lesson.html`, `assets/lesson-*`: 공통 수업 기능과 기존 실험 모듈
- `platform-config.js`: 테스트 서버 주소와 브라우저 저장 키
- `supabase/functions/`: 설치한 서버 함수
- `supabase/schema/`: 기본 자료 스키마, 잠금 수정, 퀴즈 결과 연결 SQL. 새 설치에서는 `content-platform.sql` 다음에 `lock-patches.sql`, `quiz-results-bridge.sql`을 적용합니다.
- `tests/`: `node --test tests/*.test.mjs`와 실제 DB용 `quiz-results-bridge.integration.sql`
- `tools/`: 기존 HTML 이관·초기 자료 등록 보조 도구

DB용 검증 SQL은 지정한 테스트 프로젝트에서만 실행합니다. 비공개 초기 등록 자료와 실제 인증 키는 이 저장소에 포함하지 않습니다.
