## 교사가 사용하는 순서

1. 교사 로그인 → **관리자 모드 → 📚 자료 관리**를 연다.
2. 내용 파일로 새 차시를 추가하려면 **수업자료 가져오기**를 선택한다. 기존 수업 수정은 **본문·버전 관리**를 선택한다.
3. 문구·본문·문항을 편집하고 **실제 수업 미리보기**에서 저장 전 내용과 실험·형성평가를 확인한다.
4. **교사 전용 새 버전으로 저장**한 뒤 목록의 **수업 미리보기**에서 확인하고 **학생 공개**를 선택한다.
5. 연결된 단원·차시·활동·학습지 잠금도 확인한다. 이미 접속한 학생은 목록을 새로고침한다.

기존 실험 수업은 **문구만 편집 · HTML 구조 유지**로 텍스트를 변경할 수 있다. 도형 구조나 동작 변경은 고급 HTML·CSS·JavaScript 편집으로 처리한다. 외부 라이브러리 URL 연결은 지원하지 않는다. 실험 코드는 수업팩 안에 두고 공통 로그인·잠금·채점·제출 코드를 편집 대상에서 분리한다.

v3의 **실제 수업 미리보기**는 학생 수업과 같은 렌더러·격리 실험·형성평가 화면을 사용한다. 답과 연습 제출은 메모리에서만 처리하고 학생 기록·포인트·잠금을 변경하지 않는다. 일반 HTML과 이전 수업 형식의 본문 미리보기는 기존처럼 스크립트를 실행하지 않는다. 새 공통 수업과 기존 15차시 이관은 `science-lesson/v3`를 사용한다. 이전 v1/v2 내용 버전도 호환되며, 이미 시작한 v3 응시는 당시의 공개 본문·문항·정답을 유지한다.

파일 업로드는 그대로 지원한다. 내용 가져오기 ZIP·단일 JSON은 8MB, 압축 해제 후 파일당 2MB·전체 12MB 이내다. PDF는 10MB, 기존 HTML·실행 수업팩 JSON은 2MB 이하이며 Word·한글·PPT 직접 편집이나 임의 문서의 자동 수업 변환은 포함하지 않는다. 학습지의 `lesson_id`가 해당 차시와 일치하면 차시 PDF 패널에도 연결한다.

## 보관·내용 버전·공개

- **보관**은 자료를 삭제하지 않고 교사 보관함으로 옮긴다. 보관한 자료는 교사 전용으로 꺼낸 뒤 내용을 확인한다.
- **이 버전으로 되돌리기**는 이전 내용을 새 버전으로 저장한다. 자료 ID와 기존 제출 기록은 유지하며 현재 버전의 기록도 남는다.
- 버전 기록은 이번 기능 설치 때 보존한 현재 상태부터 시작한다. 그 전에 덮어쓴 내용이 기록에 없으면 복구할 수 없다.
- 본문 저장·파일 교체·복원 후에는 교사 전용 상태에서 확인하고 별도로 학생 공개한다. 새 파일 등록은 임시저장 상태로 시작한다. 교사용 답안에는 학생 공개 경로가 없다.
- 공개와 관련 잠금이 모두 허용되어야 학생이 자료를 받는다. 학생이 이미 내려받은 사본까지 회수하는 기능은 아니다.

## 수행평가 제출·수합

`assessment.html`의 **활동 내용 제출**은 입력·측정·스케치 등의 구조화된 데이터를 접수하고 **PDF 제출**은 별도 완성 파일을 접수한다. 각각 최초 1회만 제출하며 교사가 해당 종류의 재제출을 허용하면 새 제출본을 추가한다. 재제출 허용은 한 번 소진되고 이전 제출본은 보존된다. 기기 임시저장·인쇄·PDF 저장만으로는 서버 제출이 완료되지 않는다.

교사는 **교사 제출물 수합**에서 평가를 선택하고 학번순으로 최신 제출본과 이전 이력을 확인한다. **활동지 열기**는 원래 양식에 개별 제출 내용을 복원한다. 여러 학생의 일반 활동 내용 인쇄는 입력·측정 데이터 목록이며 PDF는 개별 열기·다운로드 후 인쇄한다. 자동 PDF 병합은 구현 범위에 포함하지 않는다.

운영 플랫폼에 쌓인 과거 제출 이력을 이번 테스트 서버로 복사하지 않았다. 새로운 양식은 특수 입력·복원 어댑터의 연결을 확인해야 한다. 임의 HTML의 모든 내부 상태가 자동 수합되는 것은 아니다.

## 계정 활성화와 자료 보호

**🔑 계정 활성화**에서 최초 등록 대기 계정에 24시간 일회용 코드를 발급한다. 코드는 해당 학생에게 개별 전달하며 원문은 발급 화면에서만 확인한다. 재발급은 이전 미사용 코드를 폐기한다. 학생은 **처음 접속하나요? 계정 활성화**에서 학년도·학번·코드와 새 비밀번호를 입력한 뒤 일반 로그인을 이용한다. 가입 완료 계정의 기존 비밀번호는 그대로 유지한다.

자료 API는 서버 세션·만료·현재 계정 상태·권한·공개·잠금을 확인한다. 자료·정답·내용 버전·평가 제출 테이블은 직접 클라이언트 접근을 제한하고 PDF는 비공개 저장소에 둔다. 편집 화면의 비공개 정답은 관리자 모드 종료 시 지운다. 실험 iframe에는 인증 세션을 전달하지 않는다.

형성평가는 학생이 보낸 선택 번호를 서버 비공개 정답으로 다시 채점한다. 기존 현황판·최초/최고 제출 기록과 연결하며, 최초 제출 포인트와 중복 요청 처리를 트랜잭션으로 수행한다. 클라이언트가 보내는 임의 점수는 채점 근거로 사용하지 않고 예전 점수 제출 경로는 차단한다.

**과거 Git 커밋에 공개됐던 평가·답안은 이번 변경으로 지워지지 않는다.** 현재 공개 파일에서 답안을 분리했지만 이미 공개된 내용을 다시 비밀로 만들 수는 없다.

## 검증 완료와 미검증 범위

기존 자료 등록·보관·복원 개편에서는 실제 HTTP와 DB로 학생 로그인, 자료 권한, 학생의 비공개 자료·업로드 거절, 서버 재채점·현황판 연결·중복 지급 방지, PDF 원본 일치, 자료 공개·목록 반영·버전 충돌·보관·교사 전용 복원을 확인했다. 이전 검증용 계정·세션·임시 자료는 정리했다.

이번 변경은 `tests/`의 권한·버전·편집기·활성화·제출 관련 단위 검사와 트랜잭션 기반 DB 검증을 함께 사용한다. 원격 설치·실제 접수 확인 여부는 최종 배포 검증 결과를 따른다. 테스트 개수나 파일 구현만으로 실제 기기 동작까지 완료했다고 간주하지 않는다.

다음 항목은 추가 확인 또는 후속 작업이다.

- **실제 태블릿 기기:** 펜 필압·손바닥·확대·PDF 필기 내보내기, 마이크 권한·중지, 모든 15개 실험의 터치·회전·화면 크기별 동작. `device-check.html`은 직접 확인용 도구이며 자동 기기 인증 결과가 아니다. 입체 그림 검사는 Canvas 2D 투영이고 WebGL 성능 검사가 아니다.
- **기존 관리자 기능의 실제 업무:** 학년도 전환, 전체 명단 변경, 회원 승인, 기존 학생 권한 변경을 실제 데이터로 모두 실행하지 않았다. [기능별 API 점검 기록](docs/admin-compatibility.md)에 확인한 계약과 한계를 기록한다.
- **관리자 API 전체 보안 통합:** 일부 기존 API는 새 자료 API와 동일한 계정 상태 재검증을 공통 사용하지 않는다. 모든 세션·권한 철회 경로를 통합한 것은 아니다.
- **새 평가 양식:** 임의 평가 문서의 모든 상호작용·특수 상태 자동 이관, 자동 PDF 병합, 모든 양식의 일괄 조판은 별도 검토가 필요하다.

일시적인 서버 503·지연이 있을 수 있다. 요청은 최대 60초를 기다리고 변경 요청을 자동 재전송하지 않는다. 저장 응답을 확인하지 못하면 목록·버전을 먼저 조회해 중복 등록을 피한다.
