테스트 기기 점검

수업 전에 한 번 확인해 주세요

수업에 사용할 태블릿과 브라우저에서 직접 확인하는 화면입니다. 필기와 음성은 저장하거나 서버로 전송하지 않습니다.

1. 펜·터치 필기

입력 대기

아래에 선과 글자를 써 보세요. 펜을 약하게·강하게 누르고, 지우개도 확인해 주세요.

아직 그리지 않았습니다.

펜 사용 시 손가락 입력을 끄면 손바닥으로 생기는 선을 줄일 수 있습니다. 필압이 일정하게 표시되는 기기에서는 실제 선 굵기도 확인해 주세요.

2. 마이크·파형

꺼짐

시작 버튼을 누르고 마이크 사용을 허용한 뒤, 짧게 말하거나 손뼉을 쳐 보세요.

녹음하지 않습니다. 60초 후 또는 이 화면을 떠나면 자동으로 꺼집니다.

3. 입체 그림 회전

조작 대기

그림을 좌우로 끌거나 각도를 바꿔 보세요. 자동 회전 중에도 끊김이 있는지 확인해 주세요.

기존 실험과 같은 Canvas 2D 투영 방식의 점검입니다. WebGL 성능 검사가 아니며, 모든 실제 실험의 정상 동작을 보장하지는 않습니다.

점검 결과 보내기

문제가 있으면 결과를 복사해 대화에 붙여 넣고, 기기 종류와 어떤 동작이 불편했는지 함께 알려 주세요.

체크 표시는 사용자가 직접 확인한 결과입니다. 실제 기기 검증이 자동으로 완료되는 것은 아닙니다.
