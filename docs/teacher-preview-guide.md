# 코드 없이 수업을 확인하는 방법

[테스트 플랫폼 열기](https://chemtea.github.io/Curr.2022-Science-2-Server-Test/)

수업을 확인할 때 JSON이나 HTML 코드를 읽을 필요가 없습니다. **실제 수업 미리보기**에서 학생 수업과 같은 화면으로 단계를 이동하고 실험·형성평가를 조작합니다. 저장하지 않은 내용도 확인할 수 있습니다.

## 새 수업자료를 받았을 때

1. 교사 로그인 후 **관리자 모드 → 자료 관리 → 수업자료 가져오기**를 엽니다.
2. 수업 내용 ZIP·JSON을 고르고 제목·단원·차시를 확인합니다.
3. **실제 수업 미리보기**를 누릅니다. 가운데 큰 창에서 1~3단계의 본문·실험을 확인합니다.
4. 4단계에서 답을 골라 정답·오답 피드백과 관련 단계 이동을 확인합니다. 모든 문항을 선택하면 연습 제출할 수 있습니다.
5. 미리보기를 닫고 **교사 전용으로 새 차시 등록**을 누릅니다. 수정이 필요하면 **본문·피드백 편집**을 엽니다.
6. 확인한 수업을 자료 목록에서 **학생 공개**합니다. 단원·차시·단계의 실제 잠금 설정도 확인합니다.

미리보기 버튼을 누르는 것만으로 자료가 저장되거나 학생에게 공개되지는 않습니다. JSON 원본은 시스템이 읽는 등록 파일이며 교사가 직접 코드로 확인해야 하는 문서가 아닙니다.

## 기존 수업을 수정할 때

**자료 관리 → 본문·버전 관리**에서 문구·문항·피드백을 수정한 뒤 **실제 수업 미리보기**를 누릅니다. 아직 저장하지 않은 현재 편집 내용으로 열립니다. 닫으면 작성 중인 편집 화면으로 돌아옵니다. 저장을 선택하면 교사 전용 새 버전이 되고, 별도로 학생 공개합니다.

자료 목록의 **수업 미리보기**는 서버에 저장된 최신 내용을 확인하는 링크입니다. 편집 중인 미저장 내용은 편집기 안의 미리보기에서 확인하세요. 이전 버전의 **내용 확인**은 해당 버전의 본문·문항·교사용 피드백을 함께 사용하며, 복원 버튼을 누르기 전에는 현재 수업이 바뀌지 않습니다.

## 미리보기에서 확인할 수 있는 것

| 항목 | 미리보기 동작 |
|---|---|
| 화면 | 학생 수업과 같은 제목·탭·본문·실험·문항 렌더러 사용 |
| 단계 이동 | 모든 단계를 열어 수업 흐름과 관련 단계 복습 연결 확인 |
| 실험 | 해당 차시의 실험 코드를 기존 격리 실행 화면에서 조작 |
| 형성평가 | 최초 선택 고정, 정오답 피드백, 전체 답 선택 후 연습 제출 |
| 제출 후 복습 | 다른 답을 골라 피드백 확인, 최초 연습 점수 유지 |
| 다시 시작 | 임시 풀이를 지우고 다른 답으로 수업 검토 |
| 화면 너비 | 데스크톱·태블릿·휴대전화 너비로 배치 확인 |

교사 미리보기의 연습 점수는 임시 값입니다. 학생의 답안·학급 현황·포인트 잔액·지급 내역·잠금 설정을 바꾸지 않습니다. 실제 제출과 포인트 지급은 학생 계정의 수업 화면에서 확인합니다. 미리보기에서 모두 열린 단계가 실제 학생에게도 공개되었다는 의미는 아닙니다.

## 지원 범위

실제 수업 미리보기는 새 공통 수업 형식(`science-lesson/v3`)을 지원합니다. 이관한 기존 15차시와 내용 양식으로 가져오는 새 차시가 대상입니다. 일반 HTML·PDF와 이전 형식의 내용 확인은 기존 문서 미리보기를 사용합니다. 임의 HTML을 올리면 공통 수업으로 자동 변환되는 기능은 아닙니다.

미리보기 링크는 교사 권한으로 열어야 합니다. 교사용 정답이 든 원본을 URL·공개 저장소에 넣지 않습니다. 창을 닫거나 계정이 바뀌면 임시 미리보기 데이터를 지웁니다.

태블릿 너비로 보는 것은 화면 배치 확인입니다. 펜 입력·손바닥 인식·마이크 권한·3D 성능의 실기기 검증을 대신하지 않습니다. 이번 개선에는 독립 HTML 내려받기나 임의 실험을 화면에서 조립하는 편집기는 포함하지 않습니다.
