# 테스트 배포 검증 기록 · 2026-09-13

대상: `Chemtea-lab / science-platform-test` (`rerykeslgwhamreoskgx`) 및 `Chemtea/Curr.2022-Science-2-Server-Test`. 운영 서버는 변경하지 않았다.

## 반영 사항

- 자료 관리 버튼의 권한 확인 중 위치 유지, 중앙 팝업·명확한 테두리·내부 스크롤.
- 화면 내 새 수업 작성·본문/문항/정답 편집·내용 버전 확인 및 교사 전용 복원.
- 기존 15차시·60문항의 서버 수업팩 이관. 기존 자료 ID와 공개·보관 상태 보존. 원본 에너지 전환 문항의 5선지 정합성 보정.
- 최신 수행평가 문서의 격리 실행, 활동 내용과 PDF 별도 제출·교사 수합·재제출 허용. 신규 평가와 교사용 양식은 비공개.
- 교사 발급 24시간 일회용 계정 활성화 및 기존 최초 등록 경로 차단.
- 로그인 함수의 현재 계정·역할·세션·동의 검사, 누락된 학생 개별 생성 API, 새 수업 현황판 연결.

## 확인한 결과

- 자동 검사 117개 통과. 권한·보관·버전·편집기·활성화·격리 실험·평가 제출·잠금·세션 구분을 포함한다.
- 내용 버전·활성화·평가 제출 DB의 원자적 처리와 직접 접근 제한 검사 통과. SQL 검증용 자료는 트랜잭션으로 롤백했다.
- 실제 HTTP로 본문/정답 수정, 이력 조회, 충돌/잘못된 버전 거부, 같은 ID의 교사 전용 복원을 확인했다.
- 실제 PDF 두 개를 각각 올리고 교체한 뒤, 과거/새 버전 복원 결과가 각각 원래 파일의 바이트와 일치했다.
- 실제 HTTP 활성화·로그인·세션 검사 31개 통과. 최초 활성화·다른 계정 코드 사용 차단·재사용 차단·폐기 및 정상/정지/만료 계정의 차이를 검증했다.
- 합성 학생의 계정 생성과 등록대기·활성화 필요 상태를 확인했다.
- 실제 수행평가 데이터/PDF 제출, 같은 요청 중복 방지, 학생 자신의 다운로드, 다른 학생 접근 거부, 교사 수합, 재제출 후 이전본 보존을 확인했다.
- GitHub Pages 배포 성공. 공개 화면에서 관리자 탭 숨김, 중앙 정렬용 fixed/auto 및 2px 테두리 적용, 새 스크립트 로드와 기기 점검의 회전 동작을 브라우저에서 확인했다.

## 남은 검증과 제한

- 실제 태블릿·펜·마이크 기기를 사용하지 않았다. 모든 15개 실험과 평가 문서의 실제 조작·PDF 필기·인쇄도 해당 기기에서 확인해야 한다. `device-check.html`은 이를 위한 점검 도구다.
- 기존 관리자 API 전체의 보안 공통화, 실제 학년도 전환·명단/권한 일괄 변경은 수행하지 않았다. `admin-compatibility.md`의 범위를 참고한다.
- 버전 기록 도입 전에 저장되지 않았던 과거 내용을 복구하는 기능은 아니다.
- 일부 검증 요청에서 503 및 긴 지연을 관측했다. 같은 기능의 후속 검사와 재배포 뒤에는 통과했지만 오류 원인을 확정하지 못했다. 변경 요청은 자동 재전송하지 않으며, 응답이 불확실할 때 현재 버전/제출 상태를 먼저 확인하도록 구성했다.
- 현재 비공개 처리로 과거 Git 기록이나 이미 배포된 답안 사본이 삭제되지는 않는다.
