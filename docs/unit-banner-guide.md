# 단원 문양과 색상 바꾸기

테스트 플랫폼에서 교사 로그인 후 **관리자 모드 → 단원 꾸미기**를 누릅니다. 단원 선택 화면의 각 배너에 있는 **문양·색상 변경**으로 해당 단원을 바로 열 수도 있습니다.

1. 꾸밀 단원을 선택합니다.
2. 문양 21종 중 하나를 고릅니다. 자동차, 원소, 삼각플라스크, 은하, 태양, 지구, 번개, 빛, 별, 우주, 화합물, 물질, 꽃, 동물, 세포, 나뭇잎, 나무, 컴퓨터, 책, 자석, 파동을 제공합니다.
3. 추천 팔레트 12개 중 하나를 고르거나 색상 선택기·6자리 HEX 코드로 직접 지정합니다. **3단원 기본**, **7단원 기본**은 기존 배너의 색상 조합입니다.
4. 단색 또는 그라데이션을 선택합니다. 그라데이션은 두 색상과 방향을 바꿀 수 있습니다.
5. 미리보기를 확인하고 **변경사항 저장**을 누릅니다. 저장하기 전에 닫으면 편집 중인 설정은 적용되지 않습니다.

저장한 디자인은 서버에 보관됩니다. 다른 기기에서도 플랫폼을 새로 열거나 새로고침하면 같은 디자인을 받습니다. 다른 화면에서 먼저 변경했다면 최신 설정을 불러온 뒤 다시 편집합니다.

새 단원은 7단원의 문양·테마를 복제하지 않습니다. 8단원은 은하 문양과 보라·분홍 그라데이션으로 시작하며 이후 교사가 바꿀 수 있습니다. 단원별 디자인은 수업 내용과 별도로 저장되므로 차시를 추가해도 유지됩니다.

디자인 저장은 수업 공개 여부·잠금·형성평가·포인트에 영향을 주지 않습니다. 학생에게 비공개인 단원의 디자인도 학생 목록으로 전달하지 않습니다. 편집과 저장은 서버에서 교사 관리자 권한을 확인합니다.
