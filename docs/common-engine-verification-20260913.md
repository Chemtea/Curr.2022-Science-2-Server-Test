# 공통 수업 엔진 검증 기록 · 2026-09-13

대상은 [GitHub 테스트 사이트](https://chemtea.github.io/Curr.2022-Science-2-Server-Test/)와 Supabase의 `science-platform-test` 프로젝트입니다. 운영 사이트와 운영 DB는 이번 검증 대상이 아닙니다. 학생 개인정보와 인증키는 이 문서에 포함하지 않았습니다.

## 확인한 결과

**새 차시 하나를 공통 코드 수정 없이 내용 파일로 등록하고, 서버 채점 결과가 기존 포인트와 학급 현황에 연결되는 것을 실제 HTTP 요청으로 확인했습니다.** 테스트 차시는 「새 차시 테스트 · 거울의 반사각 탐구」(`unit_demo` / `demo_reflection_l1`)입니다.

| 확인 범위 | 결과와 근거 |
|---|---|
| 실제 서버 가져오기 | 수업 원본 변환 결과를 기존 저장 API로 등록. 교사 전용 상태에서는 학생 열기 거부, 공개 후 학생 카탈로그와 수업 열기 성공 |
| 권한 분리 | 학생의 자료 등록·교사용 편집 데이터 조회 거부. 비로그인 수업 열기 거부. 학생 응답에 교사용 정답 문서 미포함 |
| 최초 선택 | 첫 선택과 피드백 저장. 다른 답으로 변경 거부. 다시 불러와도 같은 선택 유지. 타 계정의 시도 접근 거부 |
| 제출 조건 | 미완료 제출과 제출 전 자유 복습 거부. 클라이언트가 보낸 가짜 만점과 답 배열을 무시하고 서버에 저장된 최초 선택으로 채점 |
| 포인트 | 학생 검증 계정 A는 3/4 → 15P, B는 4/4 → 20P. A의 15P는 기존 포인트 조회·지급 내역 API에서도 확인 |
| 중복 처리 | 최종 제출 재요청과 제출 후 다른 답 복습에도 최초 점수·포인트 유지. A의 DB 직접 조회에서 잔액 15P, 지급 원장 1건, 학습 제출 1건, 최초 제출 1건 확인 |
| 학급 현황 | 실제 관리자 현황판 API에서 검증 학생 두 명의 3/4·4/4와 제출 인원 2명 확인. 새 차시의 통계 항목도 포함 |

HTTP 통합 검증은 8개 시나리오 그룹을 통과했으며, 위 학급 현황은 추가 읽기 전용 요청으로 별도 확인했습니다. 기존 포인트 규칙 자체는 변경하지 않았습니다. 4문항 최초 제출 기준 20·15·10·5·1P이며, 같은 계정과 수업 ID에는 최초 1회만 지급됩니다.

## 코드·자료 검증

- SQL 통합 검사 51개: 최초 선택 고정, 시도별 내용 버전 보존, 선택한 답에 필요한 피드백, 제출 후 복습, 기존 제출 기록 존중, 역할·소유권·잠금 검사, 서비스 전용 함수 권한을 확인했습니다. 검사 트랜잭션의 합성 데이터는 롤백했습니다.
- Node/VM 회귀 검사 **99개 통과, 실패·건너뜀 0개**: 공통 형성평가 상태 전환, 계정 전환 중 늦게 도착한 응답 차단, 가져오기 파일 검사, 공개·비공개 문항 분리, 편집·버전 관리, 카탈로그 연결, 기존 수업 형식 호환을 검사했습니다. VM 검사는 실제 브라우저 화면 검증과 구분합니다. 버전 9 API에서 시작한 공개 스냅샷 반환·비공개 정답 미포함·잔액 15P 유지도 실제 HTTP로 재확인했습니다.
- 기존 15차시를 내용 양식으로 변환했습니다. 학습 본문 45개와 형성평가 60문항을 대상으로 보기·선택지·피드백·관련 단계 연결을 비교했습니다. 정답과 해설 원본은 공개 저장소에 포함하지 않습니다.

기존 15차시의 서버 이관도 완료했습니다. 서버 집계: v3 수업 15개, 사용 중 14개·보관 중 1개, 학습 본문 45개, 형성평가 60문항, 보기 4개, 오답 설명 182개. 공개 문항의 정답·해설 키 필드는 0개입니다. 기존 서버 본문을 대조한 뒤 변경했으며 원래 수업 ID·자료 ID·보관·공개·잠금 상태와 기존 제출·포인트 기록을 보존했습니다.

## 아직 확인하지 못한 범위

공개 GitHub 사이트에서 새 단원과 새 차시 링크, 비로그인 수업 접근 거부를 확인했습니다. 실제 로그인한 브라우저의 전체 클릭 흐름과 화면 배치, 태블릿 필기·마이크·3D 하드웨어 동작은 검증 완료가 아닙니다. 동시에 연결된 여러 클라이언트의 실제 경합 시험도 위 순차 HTTP 검사와 별도입니다.

학습지의 독립된 열기 흐름과 누락 PDF 4개, 수행평가의 모든 상호작용·제출·수합, 기존 포인트 API의 현재 계정 정지·필수 동의 검사 통일은 추가 작업이 남습니다. 기존 플랫폼의 디자인·구조·기능 전체가 완전히 이관되었다고 판정하지 않았습니다.

직접 확인하는 순서는 [공통 엔진 테스트 안내](common-engine-test-guide.md)를 참고하세요.

배포 대상은 테스트 저장소와 `rerykeslgwhamreoskgx`의 content-api v9입니다. 새 차시 ID나 단원 ID를 공통 실행 코드에 추가하지 않았습니다. 검증용 계정·세션·포인트 데이터는 정리하고 새 수업자료는 남깁니다.
