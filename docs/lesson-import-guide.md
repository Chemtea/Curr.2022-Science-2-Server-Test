# 수업자료 가져오기 · 본문 편집 안내

수업 내용을 올리면 공통 화면이 단계 이동, 잠금, 형성평가, 제출, 포인트 연계를 담당합니다. 차시를 추가할 때 GitHub 코드나 공통 엔진을 수정할 필요가 없습니다.

## 새 수업 등록

1. 메인 화면에서 교사 계정으로 로그인하고 관리자 모드를 켭니다.
2. **자료관리 → 수업자료 가져오기**를 누릅니다.
3. 준비된 수업 내용 ZIP 또는 단일 JSON 파일을 선택합니다. 여러 차시가 들어 있는 ZIP은 가져올 차시를 선택할 수 있습니다. 한 번에 한 차시를 등록합니다.
4. 자료 제목, 단원 ID·이름, 수업 ID를 확인합니다. 기존 차시와 같은 수업 ID로 새 자료를 만들 수 없습니다.
5. 단계 이름과 문항 수를 확인합니다. **본문 모양 미리보기**는 본문만 보여 줍니다. 실험 스크립트와 마이크는 이 미리보기에서 실행하지 않습니다.
6. **교사 전용으로 새 차시 등록**을 누릅니다. 등록한 수업을 열어 내용을 확인합니다.
7. 자료관리의 해당 수업에서 **학생 공개**를 선택합니다. 단원·차시·단계가 잠겨 있다면 잠금 설정도 해제해야 학생이 사용할 수 있습니다.

저장 실패나 연결 지연이 발생하면 자료 목록을 새로고침해 먼저 확인하세요. 같은 등록 요청을 다시 보내도 기존 자료를 덮어쓰지 않도록 ID와 버전을 검사합니다.

## 기존 수업 수정

자료관리 목록에서 **본문·버전 관리**를 누릅니다.

| 편집할 내용 | 편집 위치 |
|---|---|
| 화면 제목·부제목·하단 문구·너비 | 차시 제목과 표시 |
| 1~3단계 제목·본문 | 단계별 수업 본문 |
| 실험 구조를 유지하며 문구 수정 | 문구만 편집 · HTML 구조 유지 |
| 문제·보기·선택지·복습 이동 | 형성평가 문항과 교사용 정답 |
| 정답 번호·정답 설명·힌트·선택지별 오답 이유 | 같은 문항의 교사용 피드백 항목 |
| 해당 차시의 실험 동작 | 실험 HTML · CSS · JavaScript 편집 |
| 이전 내용 확인·복원 | 이전 내용 버전 |

저장하면 교사 전용의 새 버전이 생깁니다. 내용을 확인한 뒤 학생 공개를 다시 선택하세요. 복원도 과거 내용을 새 버전으로 만들어 기록을 남깁니다. 수업 내용을 수정하거나 복원해도 기존 학생의 최초 답안·제출 결과·포인트가 초기화되지 않습니다.

공통 수업의 학습 본문은 세 단계이며 형성평가가 네 번째 단계입니다. 본문 단계 ID는 유지됩니다. 실험 HTML의 ID·버튼 연결·도형 구조를 변경할 때에는 해당 실험 코드도 함께 확인해야 합니다.

## 형성평가 운영

- 첫 선택을 서버에 저장한 뒤 정답 여부와 해당 선택의 피드백을 보여 줍니다. 제출 전에는 그 문항의 첫 선택을 바꿀 수 없습니다.
- 오답 이유·힌트·정답 해설은 교사용 원본에서 따로 관리합니다. 학생에게는 서버가 허용한 피드백만 전달합니다.
- 모든 문항을 선택한 뒤 최종 제출합니다. 제출 결과는 기존 학습 결과 저장과 포인트 지급 처리에 연결됩니다.
- 제출 후에는 선택지를 다시 눌러 복습할 수 있습니다. 복습은 최초 점수와 지급된 포인트를 바꾸지 않습니다.
- 관련 단계로 이동하는 복습 버튼도 해당 단계의 잠금 설정을 따릅니다.

포인트는 브라우저가 보낸 점수를 믿고 지급하지 않습니다. 서버에 기록한 최초 선택을 기준으로 채점하고 기존 포인트 지급 규칙을 사용합니다. 실제 지급 내역은 학생의 포인트 화면에서 확인할 수 있습니다.

## 자료 파일 준비

지원하는 자료는 `science-lesson-source/v1` 구조의 ZIP 또는 이를 한 파일로 묶은 `science-lesson-import/v1` JSON입니다. **공통 수업팩 양식 받기**는 빈 문항·빈 정답의 단일 JSON 양식을 내려받습니다. 필수 내용을 채워야 등록할 수 있습니다.

차시마다 필요한 내용은 다음과 같습니다.

- 수업 제목·단원·차시 ID와 세 단계 본문
- 해당 차시의 실험 코드·스타일과 공통 실험 연결 정보
- 형성평가 1~5문항: 문제, 보기, 선택지 2~6개, 관련 단계
- 교사용 정답: 정답 선택지, 정답 피드백 제목, 상세 해설, 힌트, 각 오답 선택지의 이유

일반 문서나 학습 내용만 보내도 이 형식으로 정리할 수 있습니다. 새로운 종류의 실험은 그 실험 동작을 구현하는 차시 전용 코드가 필요할 수 있습니다. 공통 로그인·잠금·채점·포인트 코드는 수업 원본에 포함하지 않습니다.

기존 소단원 전체 HTML을 ZIP으로 묶는 것만으로는 이 자료 형식이 되지 않습니다. 기존 공통 기능을 분리하고 본문·실험·문항·교사용 피드백으로 변환한 자료를 사용하세요.

수업 파일은 UTF-8 텍스트여야 합니다. ZIP·JSON 파일은 8MB, 파일당 압축 해제 크기는 2MB, 전체 압축 해제 크기는 12MB, 파일 개수는 256개까지 지원합니다. 일반 ZIP의 저장·Deflate 압축을 지원하며 암호화·분할·ZIP64·심볼릭 링크는 지원하지 않습니다. 브라우저가 ZIP 압축 해제를 지원하지 않으면 단일 JSON을 사용하세요.

교사용 원본에는 정답과 해설이 들어 있습니다. 원본 ZIP·JSON을 학생에게 공유하거나 공개 GitHub 저장소에 올리지 마세요.

## 학습지

원본 자료에 적힌 `worksheets/...pdf` 경로는 실제 업로드된 PDF가 아닙니다. **자료관리의 학습지 업로드**에서 PDF를 올리고 수업 ID에 연결하세요. 수업 내용 ZIP에 포함된 학습지는 이 가져오기에서 자동 등록하지 않습니다.

## 실제 수업 전 확인

새 차시는 교사 전용 상태에서 실험 조작, 세 단계 이동, 형성평가의 보기·피드백·복습 연결을 확인한 뒤 공개하세요. 마이크·음성·3D·태블릿 필기는 실제 사용할 기기와 브라우저에서 권한과 입력을 확인해야 합니다.
