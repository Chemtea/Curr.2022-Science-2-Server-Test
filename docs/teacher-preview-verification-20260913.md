# 실제 수업 미리보기 검증 · 2026-09-13

대상은 `Chemtea/Curr.2022-Science-2-Server-Test` 테스트 사이트입니다. 이번 변경은 프런트엔드와 안내 문서이며 Supabase 테이블·함수·계정·포인트 데이터는 변경하지 않았습니다.

## 구현

`lesson-loader.js`의 본문·문항 렌더러, `lesson-sandbox.js`의 격리 실험 실행, `lesson-quiz.js`의 최초 선택·피드백·제출 후 복습 화면을 실제 수업과 미리보기가 함께 사용합니다. 단계 표시도 `lesson-navigation.js`를 공유합니다. 미리보기만 별도 메모리 채점 경로로 연결하며, 학생 수업은 기존 서버 채점과 포인트 지급 경로를 유지합니다.

가져오기와 편집기의 현재 입력 내용, 저장된 수업, 선택한 과거 버전을 각각 확인할 수 있습니다. 미리보기는 자동 저장·복원·학생 공개를 실행하지 않습니다. 기존 문서 미리보기는 이전 형식과 일반 HTML에 유지합니다.

관련 회귀 검사 **96개 통과, 실패·건너뜀 0개**입니다. 변경 JavaScript 9개와 index 내부 스크립트 2개의 구문 검사도 통과했습니다.

## 검증 항목

| 범위 | 확인한 결과 |
|---|---|
| 교사 권한 | 기존 서버 관리자 API의 응답을 확인한 뒤 열기. 학생 역할 응답 및 인증 오류 거부 |
| 임시 내용 전달 | 같은 출처·정확한 미리보기 창·일회성 채널 확인. 잘못된 메시지·이전 창의 메시지 거부 |
| 개인정보·정답 | 인증키를 전달 자료에서 제외. 정답은 교사용 창의 메모리에만 보관하고 실험 iframe·URL·브라우저 저장소에 전달하지 않음 |
| 형성평가 | 실제 공통 퀴즈 코드를 실행해 최초 답 고정·선택별 피드백·복습 단계 이동·연습 제출·제출 후 복습 확인 |
| 실제 기록 보호 | 미리보기에서 실제 채점·포인트 API 호출 및 잔액 갱신 이벤트 0건. 연습 제출은 실제 지급 0P로 표시 |
| 종료 처리 | 닫기·계정 변경·늦은 서버 응답·스크립트 로딩 중 종료 시 이전 자료를 다시 표시하지 않음 |
| 편집 상태 | 현재 미저장 본문·실험·문항·정답 전달, 원본 객체 수정 없음, 과거 버전은 해당 버전의 정답 사용 |
| 로그인 유지 | 저장된 미리보기를 같은 탭 안의 모달로 열어 새 탭에서 세션이 사라지는 문제 해결 |
| 기존 동작 | 학생 형성평가·중복 제출 처리·잠금·실험 격리·가져오기·편집·보관·업로드 회귀 검사 |

Node/VM 검사는 실제 코드와 가짜 서버 응답을 사용한 검사입니다. 로그인한 실제 브라우저에서 교사용 미리보기 전체 클릭 흐름과 화면 배치를 확인한 결과로 해석하지 않습니다. 태블릿 필기·마이크·3D 실기기 검증도 별도로 남아 있습니다.

자세한 사용 순서는 [교사용 미리보기 안내](teacher-preview-guide.md)에 있습니다.
